// HOW THE PLATFORM IS BUILT

A generic platform: it names no application, and every cluster differs only by its variables.

One image per component

Every components/<name> ships as its own signed OCI image, and the entrypoint pulls each one on the cluster's channel — or on a tag the cluster pins for that component alone.

The entrypoint is the graph

Ordering, timeouts, election gates and release pins live in one ResourceSet per cloud. make test proves every overlay is emitted and every dependsOn resolves.

Common tier, cloud overlays

Each component's cloud-neutral common/ tier is shared verbatim; aws/ and google/ carry only the dialect that differs. Guards keep the common tier neutral.

Verified end to end

Entrypoint, component images and charts are all cosign-verified by Flux, and Kyverno admits only pod images the platform pipeline signed — keyless or KMS-keyed.

Charts follow the mirror

A tag provider lists the mirrored chart versions in range, so a flux-containers publish rolls out on the next reconcile — bounded by per-cluster *_SEMVER overrides.

Rendered like the cluster does

make test substitutes exactly as kustomize-controller does, renders every ResourceSet and kubeconforms the result — four times, per cloud and signing mode.
